# Intake: magicuidesign/magicui

- **Read:** 2026-10-12, commit `85f97fd27b053339af74ba9dd4ca428ee25989fb` (2026-10-11), https://github.com/magicuidesign/magicui: all 79
  components in `apps/www/registry/magicui/`, their demos (`apps/www/registry/example/`), docs pages (`apps/www/content/docs/components/`)
  and registry entries (`apps/www/registry.json`; the root `registry.json` is stale and lists removed components).
- **Licence:** MIT (`LICENSE.md`, "Copyright (c) Magic UI") · assets: the components ship no media. The demos load remote media that is
  **not** taken: Unsplash and Unsplash+ photos (Unsplash+ does not allow redistribution), a Pexels video, `cdn.magicui.design` clips,
  avatars from `avatar.vercel.sh` and GitHub, flags from `flagcdn.com`, brand icons from `cdn.simpleicons.org` and inline brand logos
  (trademarks), a `pixel-image-demo.jpg` of unclear source; the Safari mockup draws toolbar glyphs that look like Apple's SF Symbols
  (licence unclear). Libraries a port would use: **cobe** (MIT, `globe`), **canvas-confetti** (ISC, `confetti`), **svg-dotted-map**
  (MIT in its repository's `LICENSE`; its npm metadata has no licence field; `dotted-map`). Checked on npm and GitHub on 2026-10-12.
- **What it is:** an MIT library of 79 animated React components for websites (shadcn registry, Tailwind v4, `motion/react` in 33 of
  them, canvas or WebGL in a few), plus a small agent skill (`skills/magic-ui/`) for installing them into React apps. 19 motions of the
  TakayuStudio reference name it as a source.

## Import plan (decided with the user, 2026-10-12)

The user reviews everything on the Gallery and decides per item, so **nothing is dropped at intake**: every one of the 79 components goes into
"Mới nhập" (`library/incoming/`, out of git) as **its own Gallery item**, including the ones the kit already has (for a side-by-side
look; their `desc_vi` ends with "Kit đã có: `<name>`"). The priorities in this report are only the **import order**. The user presses
GIỮ / BỎ per item; only GIỮ moves an item into the tracked (public) library, so licence questions are settled at GIỮ, not at import.

**Classification: the library's own three layers, no extra tags.**
1. **Group folder by purpose** (`text`, `transition`, `motion`, `effect`, `ui`, `background`, `line`, `data`, `map`... for presets; the
   layout groups for blocks). The Gallery derives its category from the group (`engine/gallery.py` `category()`).
2. **Source in `preset.json`**: `source` (`label`, `repo`, `commit`, `path` or `url`) and `license`, shown on the Gallery card as
   "Nguồn" and "License". For this source: `"source": {"label": "Magic UI: <component>", "repo": "magicuidesign/magicui", "commit":
   "85f97fd27b053339af74ba9dd4ca428ee25989fb", "path": "apps/www/registry/magicui/<component>.tsx"}`, `"license": "MIT"`
   (`globe` adds cobe, MIT, with `source.sha256`; `confetti` notes canvas-confetti, ISC).
3. **The Gallery's "Nguồn" filter** groups labels into families (`srcShort` in `library/gallery/index.html`: HyperFrames, Moworks v1,
   iart-ai (MIT), claude-animation (MIT), anime.js (MIT), else Moworks). Add the family "Magic UI (MIT)" (label starts "Magic UI") there, written like the existing five
   (one regex on the label), so "Mới nhập" can be filtered by source while the user reviews.

**Names:** by purpose inside the group; when a name is taken (in the library or by another source of the same batch), prefix the source
the way the anime.js family is named (`motion/anime-path`, `text/anime-roll`): `magic-`. Once the user has chosen, kept siblings can be
merged into one preset with a `style` param (a rename the desktop session proposes to the user, never on its own).

**What cannot run as it is gets adapted, not dropped:** content fetched from the network becomes params or the project's own media; live
mouse, hover, click or scroll becomes a scripted path or cue times on the film's timeline; frames that imitate a real product get
`"brand_ui": true`; anything of unclear licence stays in "Mới nhập" with a note in `notes` (replace or drop it before GIỮ if unsure).
The 27 components this report first left out are imported too, adapted as above: the two tweet cards with their content as
params (no fetch), `hero-video-dialog` with the project's own video, the hover / scroll ones (`kinetic-text`,
`interactive-grid-pattern`, `glare-hover`, `pointer`, `scroll-progress`, `text-reveal`, `file-tree`, `code-comparison`) driven by
a scripted cursor or cue times, `iphone` and `safari` with `"brand_ui": true` (Safari's SF-Symbol-like glyphs flagged in
`notes`), the kit duplicates as they are for comparison. The table "Không lấy và vì sao" now reads as the notes each of these
items carries on the Gallery.

**Batches:** (1) magicui, 79 items; (2) codrops, 29 items; (3) the TakayuStudio motions by category, about 100 per batch, high-priority
categories first. Each batch: write the presets in a scratch film, `kit.py library import <film> <group>/<name>` for each, `kit.py gallery
build`, then the user's review.

## Not taken, and why

Every component is imported (Import plan above). The 27 first judged "not worth it" carry that judgement as their notes (table above,
[component notes](2026-10-12-magicui-components.md)). In short: 14 duplicate a kit item that is better for films, 8 only react to a live
mouse or page scroll (the kit covers most of those too), 3 need the network at render (two tweet cards, the YouTube dialog), 2 imitate
Apple products (iPhone, Safari with SF-Symbol-like glyphs). What is not taken: every demo's remote media and brand logos, the `motion/react`
runtime, Tailwind, React itself, the shadcn install skill (`skills/magic-ui/`, for React apps, not the kit).

## Risks and open questions

1. **The kit has no globe, although `map/world` says it has.** Its description (from the HyperFrames block) promises "a rotating globe
   inset", but `library/layouts/map/world/assets/world-map.html` uses only `geoNaturalEarth` (no orthographic projection, no globe).
   The description is wrong; fixing it is out of scope here.
2. **cobe version.** magicui pins `cobe@^0.6.4`; npm's latest is 2.0.1. Vendor 0.6.4 (the look magicui tuned) unless 2.x keeps the API.
   cobe renders with WebGL: it reaches After Effects as pictures (`"ae": "png"`, KI-10).
3. **Springs.** About a third of the components animate with `motion/react` springs (stiffness / damping / mass). The port fits each
   spring with the kit's `springk(k, d)` or `ctx.track`, or `ctx.ease` for a bezier; the Gallery's `ease_fit` shows the error. Check the
   feel against the magicui docs page side by side.
4. **Upstream oddities to keep or fix knowingly:** `shiny-button`'s border gleam never renders (its gradient uses Tailwind-style
   `var(--primary)/10%` and `calc()` without spaces, invalid CSS); `aurora-text`'s wobble targets an inline span, so browsers ignore it
   and only the gradient pans. Port what shows, offer the rest as an option, say so in `notes`.
5. **AE.** 19 of the 38 targets are pictures in After Effects (gradients, filters, canvas, WebGL, backdrop blur); the rest are keyframes.
6. **Trademarks and people in demos:** the beam / orbit / dock demos use real app logos; ports use neutral glyphs or the film's own
   icons, never the logos.

- **Common port rules.** React state, `useInView`, hover and click become cue times in `film.json` (or a scripted cursor path for
  `smooth-cursor`, `dock`, `lens`, `magic-card`). Infinite CSS / motion loops become repeating tweens on the film's time. Every
  `Math.random` becomes `ctx.hash(element, index)`; canvas loops become pure functions of the frame (`ctx.code`, closed form or a
  bounded replay from the start, as the component notes describe). Container-query and viewport units become px from `ctx.W` / `ctx.H`.
  Measured layouts (beam endpoints, marquee widths, list heights) are measured once at build, since a film's layout is fixed.
- **`effect/confetti`:** canvas-confetti's update step (gravity, decay, drift, wobble, tilt, shapes) re-written with a seeded generator per
