# Ảnh tham khảo (dàn trang)

Chép vào đây ảnh, deck PDF hoặc thư mục ảnh từ các thiết kế của studio mà bạn muốn Claude học **cách dàn trang**: lưới, chữ, màu, bố cục.
Sau đó yêu cầu Claude **"nạp kho tham khảo"**; mỗi mục có thêm một thư mục `<tên>_ref` (ảnh thu nhỏ, bảng ảnh, ghi chú `REF.md`).

Kho chỉ được dùng khi brief yêu cầu, ví dụ "tham khảo kho của studio" hoặc "layout giống <tên>". Thư mục này không lên GitHub.
