# The welcome card (only when the skill is opened without a brief, or the user asks what it can do)

Send the card below **in Vietnamese**, as it is: short, nothing added. The repo's README covers the rest, so link it instead of
explaining. With a brief already in the message, skip the card and start working.

---

**Moworks Motion:** motion graphic films made in code, from a brief to MP4 / MOV or an After Effects project.

Pick what you need (or just send the brief):

| Skillset | You send | You get |
|---|---|---|
| Keep design | PSD / PSB, deck, final frames | the same design, animated (layout to 2 px) |
| Free design | copy, an idea, a product, a guideline | the story first, 3 storyboard options (or one of 13 ready looks), then the film |
| Song / lyric film | a track (+ lyrics) | cuts, words and hits on the beat; beat-synced templates |
| Remake | a reference video | its rhythm and moves, your brand, copy and music |
| Characters | a style or a reference | a character sheet to approve, then the animation |
| Talking head | interview / podcast footage | info cards, the video re-laid out (split, pip...), captions in 35 styles, words behind the speaker |
| Code change | a GitHub pull request | an explainer: the change, what it does, who shipped it |
| Deck to present | slides or a deck | a film you present live: click by click, presenter notes |

Every film: approve the storyboard / motion spec first, then review in `1. Preview.bat` (notes on the timeline) and export there
(MP4, MOV, Port to AE; other frame shapes and 4K on request).

More: the README of the repo (features, commands, tips) and `gallery.bat` (the motion library).
