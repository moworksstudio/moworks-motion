# Commands (`python engine\kit.py <command> ...` from the kit root)

Windows console: set `PYTHONIOENCODING=utf-8` first (PowerShell `$env:PYTHONIOENCODING="utf-8"`, Git Bash `PYTHONIOENCODING=utf-8 python ...`),
or Vietnamese text in the output crashes with a cp1252 encode error. The kit is 60 fps only. `<project>` = the film folder (`<film>`,
the one with `1. Preview.bat`) or its `03_HTML`; an older film's own folder also works.

| Command | What it does |
|---|---|
| `new "<Client> <Project>" [--aspect 16:9\|9:16\|1:1\|4:5] [--dir <job folder>]` | new numbered film in the job folder: `01_Brief\` (brief + the user's files), `02_Assets\` (rounds, stills), `03_HTML\` (the film), the launcher `1. Preview.bat`; `04_Renders\` (MP4 / MOV) and `05_AE\` come with the first export. `tidy <film>`: a film made before 11/10/2026 moves to this layout |
| `round <project> film [--note "..."] [--base vK]` | a film round goes to the user → `02_Assets\Rounds\Film_v<kk>\` (film.json, index.html, presets + the assets / audio new in it, files.json; nothing new when unchanged); prints the line to say in the chat; exports carry the newest vN in their names. `version` = the same |
| `round <project> storyboard [A B C] [--note]` · `round <project> assets [kind=]<file> ... [--note]` | a design round → `Storyboard_R<k>\<name>.png` (the `kit.py storyboard` sheets) / `Assets_R<k>\<characters\|locations\|props>\` (no file: the `kit.py sheet` outputs); prints the line to say |
| `rounds <project>` | every round in order (the film rounds = the player's version list), and whether the working film moved on |
| `restore <project> vK` | version K becomes the working film again (the user says "quay lại vK"); the working film is kept as a round first |
| `build <project>` | film.json → index.html (tweens written out; old file backed up to qa\backup); scene entries `{ "include": "parts/x.json" }` are long-film parts; film.json `"groove"` (`film.md`) becomes one code block; ends with the quick lint (warnings, `qa\lint.json`; `AIMK_NO_LINT=1` skips it) |
| `lint <project> [--hf]` | the quick lint alone: a logo with motion, text over text / outside the margin at rest, a blank frame after a cut, text shown too briefly to read (0.5 s + 0.3 s a word), text under 4.5:1 contrast with what is behind it (3:1 large), opacity or colour on a bouncing ease, a product render moving next to resting text, an image sequence that jumps, film.json `"checks"` that do not hold (seconds). `--hf`: HyperFrames' own linter |
| `storyboard <project> [A B C]` | gate 1: every `qa\storyboard\<name>.json` (a still film per option) built apart, film.json / index.html untouched → `02_Assets\Stills\storyboard\<name>\sheet.png` |
| `reframe <project> 9:16\|1:1\|4:5\|16:9 [--name X]` / `reframe <new film> check` | an approved film in another aspect as a NEW film next to it: content record `qa\reframe-source.json`, a first layout (a taller frame: "auto stack"), stills per scene; then re-compose what reads badly. `check`: every element and all content kept, scene times identical (`workflow/reframe.md`) |
| `tidy <project>` | an older project's root tidied: notes → `notes\`, ae → `renders\ae\`, old launchers 2-4 → Recycle Bin |
| `ref sync` / `ref add <file \| folder> [--name "..."]` / `ref list` | Moworks' own references: `sync` loads what the user put in `library\refs\video\` (films: motion) and `library\refs\image\` (layouts) |
| `preview <project> [--port N] [--no-open]` | the kit player (= `1. Preview.bat`): notes → `notes\feedback.md` (each note: Done / Delete, set by the user; Claude fixes every open note); Export panel (MP4 Export, MOV Export, Port to AE; Blur / 4K / Trong suốt asked when pressed, remembered per film in `qa\player.json`); reloads the film by itself when it changes; view tools in the ⋯ menu. `--no-open`: no window, prints the link (your own browser) and serves until stopped |
| `feedback <project>` | the user's OPEN notes in `notes\feedback.md`, numbered (Done ones left out): read it at the start of every round of fixes, never pick notes by their place in the file |
| `proxy <project> [--workers N]` | the player's smooth playback (its [Phát mượt] button runs it as a job): the film rendered once small (540 px), played while the film runs, the live film when stopped; work folder only |
| `sheet <project> [--looks a,b] [--poses p,q]` | character sheets for approval: each cast look (`presets\cast\**`) rigged and acting through every pose + expressions + hands → `02_Assets\Stills\sheet\sheet.mp4` and `<look>_poses.png` (every pose at 2x: joints). `--puppets [a,b] [--hero <picture \| video@s>]`: the film's drawn puppets (`presets\drawn\<name>`) checked by machine: every pose alone on #00FF00 against the rest pose (new holes, loose pieces, gaps at joints, boxed red), every part alone, the hero-frame difference → `02_Assets\Stills\puppets\` + `PUPPETS.md`; `round ... assets` refuses unchecked puppets or ones with holes (`--force`) |
| `compare <project> <reference video> [--every 0.5] [--from a] [--to b] [--offset s] [--old-colors "#hex,..."]` · `--shots` · `--follow x,y,w,h [--color #hex] [--tol 40] [--name n]` · `--split` | everything a remake does with its reference (`workflow/remake.md`). `--shots`: the reference alone, before building (hard cuts, sheets every 0.25 s with times and frames → `02_Assets\Stills\shots\`, `01_Brief\SHOTS.md`, its sound → `01_Brief\ref\<name>.wav` for `beats`). `--follow`: one element measured per native frame (box, centre, scale, cover in film px) → its moves, times, the 3 closest GSAP eases, overshoot → `01_Brief\ref\follow\`. `--split`: the newest MP4 export and the reference side by side, "original" / "remake" → `02_Assets\Compare\`. `--old-colors`: times where the old brand's colours are still in the film. Without a flag: the film beside a reference at the same times (the reference's native frames), sheets of 3 pairs with a 10 % grid and the difference per pair → `02_Assets\Stills\compare\` + `compare.md` (the most different times first) |
| `track <project> "<stage>"` / `end` / `report` | time (Claude working / machine in the background / waiting for the user), tokens and the API-equivalent cost per stage and per chat turn → `qa\tracking.md` (from the Claude Code session logs) |
| `stills <project> 1.5 4 ...` \| `--beats` \| `--strip <t>` \| `--cuts` \| `--phone` \| `--onion <t0> <t1> [--every s]` | stills + contact sheet → 02_Assets\Stills\<kind>\ (`--cuts`: 12 frames around every scene change; `--onion`: the frames between laid over each other, the spacing of a move; self-review: `workflow/review.md`) |
| `verify <project> [--play] [--loop]` | seek / render consistency; overlapping moves on one property; `--play`: frames played in order (as an export renders them) vs seeks; warns on text going soft when scaled; `--loop`: the seam in position and speed (last frame → first vs the frames around it). EDGE lines = sub-pixel edges of a scaled / drifting picture: not bugs |
| `collide <project> [--step 0.05]` | rule 1: text on text, something painted over text ("note" = text under a picture, readable: check the still), blank frames at cuts |
| `transcribe <project> [--lang vi\|en] [--prompt "names"] [--force]` | every voice in film.json → words with times + .srt (local Whisper) |
| `beats <project> [<audio>] [--bpm 135] [--offset 0.19] [--to-bpm 124 [--force]]` | a song's tempo, beats, bars, hits, onsets → `audio\transcript\<file>.beats.json` (seconds); prints a tempo check (candidate BPMs and how well each fits) and a kick check (the waveform under 120 Hz against the grid, picture in `02_Assets\Stills\beats\`: look at it). `--fit`: moves where the film's music starts (its `"trim"`) so the built film's cuts and sound cues land on the beat. `--to-bpm`: first the track sped up / slowed down to that tempo, pitch kept → `audio\music\<file>_<N>bpm.wav` (over 8 % only with `--force`), then its grid |
| `align <project> <lyrics.txt> [<audio>] [--lang vi] [--pin "8=17.58"] [--sections "1=0; 8=17.5"] [--snap 8]` | known lyrics → a time per sung word + `01_Brief\LYRICS-TIMED.md` (local Whisper, about 3 min per minute of song the first time; what it heard is cached, so a re-run takes a second; a draft to check by ear). Sections (or `[17.5]` before a lyric line): each part heard alone with its own lines. Line starts tapped in the player (`notes\lyric-taps.json`) are used as pins; `--snap 8` after that puts words on the eighths |
| `spectro <project> [<audio>] [--from 17 --to 26]` | the singing as a picture (vocal band, beat grid, the aligned words) → `02_Assets\Stills\spectro\`: see where words start |
| `poses <project> <folder \| "assets/images/seq/f####.webp"> [--every 8]` | a product render sequence read first: numbered sheet, rest poses and slow points, portals (rest poses that show the same picture: an invisible jump), the product's box in every frame (`qa\seq-boxes.json`, widest / narrowest), `01_Brief\POSES.md` to fill (open / closed, face, which way up) |
| `measure "<text>" ... --font "<family>" --size 140 [--weight 700] [--in <project>]` | the width of a line in px with the real font |
| `measure <project> --graph <element id> [--from s --to s]` | the element's position, size, opacity and speed on every frame as a chart → `02_Assets\Stills\graph_<id>.png`, with its linear stretches and dead starts / stops |
| `cutout <project> <image> ... [--people] [--trim]` | background removal on this machine (rembg) → `assets\images\cutout\` |
| `measure <image> --locate overlay \| region \| final \| mark` | where an object is in a picture (box 0..1): pick numbered strips, never guess pixels, then check the red box (the loop: `engine/vendor/hf-locate/PROTOCOL.md`; Node.js, ffmpeg + ffprobe; it keeps a copy of Arial Bold in `C:\tmp`) |
| `cutout <project> <video> --people [--fps 25]` | the footage as frames + the person alone in every frame → `assets\video\frames\` + `assets\video\cutout\` |
| `cutout <project> <video> --people --captions [--force]` | HyperFrames' embedded captions: the clip at its own rate, the person, the words, safe zones → `assets\captions\<clip>\` + `audio\voice\<clip>.wav`; then `theme.json` / `cinematic.json` there and `text/embedded-captions` (`workflow/recipes.md` 6) |
| `mov <project> [--no-blur] [--alpha] [--4k] [--out <file>]` | finished film (= [MOV Export]): ProRes 4444, 60 fps, sound inside, motion blur on by default → `04_Renders\MOV\` |
| `mp4 <project> [--blur] [--4k] [--gif] [--out <file>]` | finished film (= [MP4 Export]): H.264 High, 60 fps, sound inside, no blur unless `--blur` (motion blur is blended in linear light) → `04_Renders\MP4\`; frames of the same film already rendered are reused. `--gif`: a GIF beside it for X (24 fps, 1200 px, one palette, exact 40/50 ms delays; X: 15 MB, 350 frames). `--4k` (`mp4` or `mov`, = 4K in the player's export question): twice the pixels on the same layout (3840×2160 for 16:9) |
| `info <project>` | the built film as the renderer sees it: size, duration, scene markers (a quick check after a build) |
| `qa <project>` | motion QA on the last MOV / MP4 render: pops, one-frame flashes, photosensitivity |
| `ae <project> --run --check auto [--no-save]` | editable After Effects project (= [Port to AE]) → `05_AE\` (grouped layers as precomps; every image sequence one footage + Time Remap) + `Audio\` (`mix.wav` + the voice / music / sfx stems) |
| `ae <project> --estimate` | the port's size first (layers x samples, MB, minutes, which elements bring the most layers): seconds |
| `ae <project> --rebuild [--check auto]` | the AE step again from the saved recording (after a port code change): about 2 min, no new recording |
| `ae <project> --jsx <fix.jsx> [--check auto]` | a script on the project open in AE (precomps, names, keys, fonts): a copy first, check frames before / after and vs the browser |
| `voice <project> [--voice <name>] [--lang vi] [--list-voices] [--yes]` | ElevenLabs voice-over for every scene voice with a "text" (prints the credits; sends only with `--yes`) |
| `music <project> "<prompt>" [--length 30] [--instrumental] [--yes]` | ElevenLabs music → `audio\music\`, then `beats` (prints the credits: 900 a minute, prices read 08/10/2026; says when the API key is missing) |
| `sfx-gen <project> "<description>" [--length 1.5] [--name x] [--yes]` | ElevenLabs sound effect → `audio\sfx\` (about 100 credits, or 11-20 a second with a length) |
| `ingest <project> "<deck.pptx>" [--slides 1-8] [--no-film] [--compare <dir> --pairs "S01=1"]` | PowerPoint / Google Slides → `deck\` (layout.json, LAYOUT.md, fonts.json) + still scenes; `--no-film`: the content only |
| `ingest <project> <owner/repo#N \| PR url>` | a pull request as the film's source → `01_Brief\pr\` (pr.json, diff.patch, people) + avatars in `assets\` (Node.js + gh; `workflow/story.md`, "A code change") |
| `psd <project> "<file.psb>" --list \| --frames "P01=Group/1" [--keep "Group/BG"] [--film] [--compare <dir> --pairs "P01=1"]` | PSD / PSB → `psd\` (PSD-TREE.md, psd.json, fonts.json, PSD.md) + layers + still scenes |
| `brand <project> <pack \| look>` | apply a brand pack of `brands\` (fonts, logos, `assets\brand.css`; `brands/pack.md`) or a public look of `library\looks\` (colours, type; then build with its `FRAME.md`: `workflow/free-design.md`) |
| `brand-check <project> <pack> [--brief [file]]` | check a film against the pack (logos animated or grooved, colours: film.json `"brand_colors"` = the pack's product / campaign colours on montage words, backgrounds, text clusters, fonts, frame 0). `--brief`: the brief vs the guideline (colours, fonts, sizes, capitals, logo motion), works before any film exists: ask the user brief or guideline for each point |
| `pulse <project> [--video f.mp4] [--from s --to s] [--bpm 135 --offset 2]` | does the picture move ON the beat: lift after the beat, beats with a visible jolt, still frames (the film rendered small, a few minutes; or an exported video in seconds), against a film that worked well |
| `font <family>` | find a font file (installed, brand packs, Adobe Fonts activated in Creative Cloud) and check its Vietnamese glyphs |
| `pdf <file.pdf> [--pages 3-5] [--in <project>]` | PDF pages → PNG on this machine (PyMuPDF comes with the kit): look at guideline pages, not only their text |
| `loudness <file.wav> [--fix out.wav]` \| `loudness <project>` | LUFS / true peak / the phone band (200 Hz - 6 kHz); `--fix` normalises to -16 LUFS, -4 dBTP. A film: the sound pass (`workflow/film.md`): the mix against its target, the latest exported MP4 and its mono fold-down, every effect over the music (aim 3 to 6 dB) and against the voice (never over it), the cuts with no sound, the cue sheet `02_Assets\Stills\audio\cues_*.png` (look at it), five timestamps for the user's headphones |
| `trash <path> ...` | to the Recycle Bin (the only way to delete) |
| `publish-check` | maintainer only, before a push to GitHub: tracked files that could carry client / NDA material (local-only folders, client-type media, brand-pack words and colours, the local deny list); read-only |
| `doctor` | is this machine ready (Python, packages, Chromium, ffmpeg, models, AE fonts, kit-root, skill versions, git, After Effects, player, disk): one line per check with its fix; run it first when a command fails on a new machine |
| `library [motion\|layout] [word ...]` | the library as one line per preset (name, description, tags, the user's notes) for choosing |
| `library import <film> <group>/<name> [--as <group>/<name>] [--layout]` · `library incoming` · `library keep\|drop <name>` | a film's clean preset into the Gallery's Incoming section (`library\incoming\`, demo + checks), what waits there, KEEP / DROP as the Gallery's buttons (`workflow/library-intake.md`) |
| `gallery build [filter]` / `gallery open` | library demo clips + machine checks / the gallery page (= `gallery.bat` in the kit root) |
| `gallery check [filter] [--static \| --random N]` | maintainer only: every demo checked into a scratch folder (the library untouched); lists presets whose result differs from the stored check. `--static`: only what needs no browser (preset.json, frame rules, as-shipped SHA-256), the part GitHub runs; `--random N`: N presets picked at random |
| `studio <project>` | HyperFrames Studio, only when the user asks to edit a timeline by hand (asks before installing) |
| `studio <project> --present` | a deck (film.json `"slides"`) in HyperFrames' presenter: slides, fragments, notes, audience tab (`workflow/film.md`, "A deck") |
| `hf status\|install\|test\|update\|rollback` | HyperFrames versions (only when HyperFrames is used) |

Kit documents: `docs\README.md`, `docs\CHANGELOG.md`, `docs\GUIDE.md` (install, update, a film, brand rules, the AE port),
`docs\KNOWN-ISSUES.md`, `docs\THIRD-PARTY.md`, `library\README.md` (preset format), `library\layouts\README.md`,
`brands\<pack>\notes.md`. On the maintainer's machine only (not in the repo): `docs\TODO.md` (open items), `docs\USER-TASKS.md`,
`docs\RECAP-SESSION.md` (the build log). The kit root holds only `install.bat`, `update.bat`, `uninstall.bat` (each asks once, `--yes` skips it, and ends
with a result table; uninstall moves everything install put on the machine to the Recycle Bin, the kit folder last), `gallery.bat` and the folders
(`.gitignore`, `.gitattributes` are there but hidden; the version is `engine\VERSION`).
**Your own Playwright script** (a client's web page to capture, any job the commands above do not cover): its first lines are
`import sys; sys.path.insert(0, r"<kit>\engine"); import common`, so Playwright uses the kit's Chromium (on a new machine it is in
`%USERPROFILE%\.aimotionkit\ms-playwright`, not Playwright's default place: clean-machine test). A web page: `goto(url,
wait_until="load", timeout=30000)` then a fixed short wait, never `networkidle` (pages with trackers never go idle); a cookie banner:
click its accept / decline button or hide it before the shot. Ask before capturing a client's site (it is a download). A 403 or a bot
check: stop at the first one (never retry, never bypass) and ask the user for the screenshots, saying which pages and where to put them.
A film chat never changes the kit (`SKILL.md` rule 9): kit bugs and ideas go into the film's handoff (`workflow/film.md`, "Handoff").
